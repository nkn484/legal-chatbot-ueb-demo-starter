# M08.3.2 Phase 1A — Transport trust provenance and citation disclosure

## Scope

Phase 1A adds immutable transport-trust provenance and retrieval/citation disclosure. It does not add or
activate pinned transport, policy grants, source registry policy mode, automatic discovery, fetch,
ingestion routing, or conversation/runtime acquisition.

## Trust semantics

| Transport trust mode | Chain | Hostname | Evidence label |
|---|---:|---:|---|
| `STRICT_TLS` | verified | verified | `OFFICIAL_LEGAL` |
| `USER_APPROVED_TOFU_PINNED_EXCEPTION` | verified | not verified; SPKI exception required later | `OFFICIAL_LEGAL_PINNED_EXCEPTION` |
| `LEGACY_UNVERIFIED` | not verified | not verified | never eligible |

Legacy `tls_verified` remains compatibility-only and equals chain + hostname verification.

## Implemented paths

- Source snapshot validates trust, policy, registry, pin-set and certificate metadata.
- Canonical snapshot hash includes trust/provenance identities.
- Migration `0006_tls_trust_provenance` backfills existing records and adds immutable checks/indexes.
- `retrieval_runs.trust_scope` records `STRICT_TLS_ONLY` or explicit pinned-exception allowance.
- Original and expansion retrieval filter provenance by trust scope and prefer strict TLS.
- Grounding/citation resolution revalidates trust scope and derives the safe evidence label.
- Chat citation identity comparison includes trust mode/label.
- Channel formatter discloses the user-approved TOFU/SPKI exception; it never calls it strict TLS.
- Historical citation identity remains persisted; Phase 1A adds no revocation/quarantine behavior.

## Migration and compatibility

- Linear head: `0005_channel_delivery → 0006_tls_trust_provenance`.
- Existing `tls_verified=true` rows backfill to strict TLS.
- Existing `tls_verified=false` rows backfill to legacy unverified.
- Direct ORM fixtures that set only legacy `tls_verified` derive strict/legacy defaults; TOFU is never
  inferred and requires complete explicit metadata.
- Downgrade removes only Phase 1A fields/constraints and is tested on a disposable database.
